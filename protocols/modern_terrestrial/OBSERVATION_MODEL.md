# Modern terrestrial observation model

**Biological process**: species distribution persistence / redistribution vs
population state dependence on North American breeding-bird routes.

**Observation process** (documented per spec §10):
- observer continuity: routes re-surveyed annually; observer identity changes
  generate apparent turnover (pending control, GAP_AUDIT §10)
- route structure: fixed roadside transects, RunType==1 filter
- detectability: auditory/visual counts; detectability varies by species and
  observer — handled via prevalence-inclusion (116 widespread species)
- survey effort: standardized start/stop protocol
- repeated sampling: multi-decade panel — supports true lag estimation
- abundance vs occupancy: BOTH retained; the occupancy/abundance divergence
  (0 vs +0.63) is itself a headline result
- spatial autocorrelation: persistent route heterogeneity, separated by
  route-demeaning in the 2×2 design
