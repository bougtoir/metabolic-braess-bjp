Caveats (from results/comparator_feasibility.json):

* **MLPF (multilayer-perceptron filter)**: architecture re-implemented from the paper; weights are not the published ones
* **EDnCNN (event denoising CNN)**: EPM labels cannot be generated for EBSSA or DND21 (no APS/IMU streams in the labelled data); the CNN is trained on the datasets' own labels
* **AEDNet (asynchronous event denoising network)**: not the published protocol: CPU inference instead of CUDA 11.3 / PyTorch 1.12, sensor frame set to that of each recording (180x240 / 240x304 for EBSSA, 346x260 for DND21) with the released 25x15 px neighbourhood, whole recording as one shape, softmax probability used as a ranking score, and <= 1500 signal + 1500 noise events scored per recording; the patch construction and model output of the re-implementation were checked to be bit-identical to the official loader and model on the authors' released sample (results/aednet_transfer.json, official_parity). No weights for DAVIS-class sensors or DVSCLEAN-style labels for EBSSA/DND21 exist, so the result is a transfer test of a fixed model, not a trained comparator
* **WedNet (window-based event denoising network)**: cannot be run or re-trained faithfully without the authors' code and weights; a re-implementation from the paper would not be the published method
* **PFD-A (polarity-focused denoising)**: binary decision converted to a ranking by neighbour support for ROC analysis; stage-2 polarity change is taken relative to the previous event at the pixel (group-processing reference code), not the first event

Datasets considered:

* **EBSSA (event-based space situational awareness)** (Afshar et al., 2020): labels: bounding-box annotations of tracked targets; per-event labels derived by box membership within +/-10 ms; ROC feasible: True; executed here: yes (43 labelled recordings, grouped 4-fold CV)
* **DND21 (DeNoising Dynamic vision sensors 2021)** (Guo and Delbruck, IEEE TPAMI 2022): labels: exact origin label: clean signal recordings (real hotel-bar segment, v2e renderings without noise) mixed with separately measured dark/light background-activity noise; ROC feasible: True; executed here: yes (dnd21_evaluation.py; leave-one-signal-source-out)
* **DVSNOISE20** (Baldwin et al., CVPR 2020): labels: Event Probability Mask: model-based per-event probability from APS+IMU, not an exact origin label; ROC feasible: False; executed here: no
* **E-MLB / END (Event Noisy Dataset)** (Ding et al., IEEE TMM 2023): labels: none; evaluated with the label-free ESR metric; ROC feasible: False; executed here: no
