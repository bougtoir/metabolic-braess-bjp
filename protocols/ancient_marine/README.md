# Ancient marine adapter (Tier 2 — ecological translation)

Palaeozoic/Mesozoic marine fossil assemblages. **Pipeline under development
in the parallel "古生代海洋回遊" session — this adapter defines the export
contract and the terrestrial→marine translation it must use.**

Marine fossil data differ fundamentally (depositional environment,
stratigraphic condensation, facies dependence, basin structure, depth
gradients, connectivity, mineralization bias, collection intensity), so
terrestrial locality definitions must NOT be forced on them. Allowed spatial
units: palaeogeographic grid, basin, shelf region, palaeolatitudinal band,
depositional province.

Trophic mapping: primary producers / primary consumers / lower guild vs
predatory / higher guild — pick whichever the available data support best
and document the choice here.
