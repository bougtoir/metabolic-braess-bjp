# Quaternary adapter (Tier 1 — strict replication, high-resolution extension)

Strict replication of the dinosaur protocol on Quaternary terrestrial
mammals, treated as a high-temporal-resolution extension of the Cenozoic
framework. **Pipeline under active development in the parallel "第四期回遊"
session — this adapter is the specification it must export into.**

Primary analysis stays dinosaur/Cenozoic-comparable (coarse aggregation).
Fine-resolution analyses (100 / 50 / 20 kyr, event-based bins) are secondary
and must additionally quantify whether higher temporal resolution strengthens
or weakens the inferred trophic contrast.

- lower trophic: herbivorous terrestrial mammals (same order rule as Cenozoic)
- higher trophic: Carnivora (terrestrial)
- spatial unit: PBDB collection
- temporal unit: primary = pooled Quaternary window or coarse bins matching
  Cenozoic; secondary = fine ladder
- required shared analyses: same guild contrast, sampling-pool experiment,
  temporal aggregation experiment, spatial turnover metric, distance-decay,
  null controls
