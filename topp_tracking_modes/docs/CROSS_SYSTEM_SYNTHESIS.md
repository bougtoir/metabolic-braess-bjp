# Cross-system synthesis — Tasks 1–5

Systems are NOT forced into a single conclusion; each keeps its own verdict.

| System | Design | Result |
|---|---|---|
| Palmyra telemetry | multi-species chl-bloom responses | null slope (−0.032, p=0.33); placebo ~50% → WEAK GO only |
| Capelin→seabird | known pulsed-prey positive control | +0.92 log birds/bin, p=0.03, LOEO-stable → WEAK POSITIVE CONTROL |
| ACCESS ecomega | 3-layer simultaneous sampling | E→P +0.0027 p=0.0002, E→K & K→P null, no attenuation → COMMON-ENVIRONMENT DOMINATED, CONDITIONAL FAIL |
| TOPP CCS | tracks + env fields + indirect prey | weak in-sample links, no event-level generalization, no mediation → MIXED-WEAK/INCONCLUSIVE, gate FAIL |

## What the pattern suggests (not a law)
- Where prey is measured directly at the right scale (capelin acoustics),
  a positive predator aggregation response is detectable.
- Where prey is indirect (chl-a) or sparse (ecomega tows, TOPP),
  predator-environment correlations appear instead — consistent with
  common environmental tracking (H1/H3) more than trophic propagation
  (H2), but equally consistent with shared seasonal confounding.
- Predictive environmental cueing (H4) was not supported in TOPP:
  env→future-chl predictability is near zero at these resolutions, so a
  cueing advantage cannot exist in this dataset regardless of animal
  behavior.

## Common bottleneck
The discriminating variable is the **prey layer**, not the predators.
Systems with co-located, event-resolved prey measurements are needed to
separate H2 from H1/H3. Recommend next: South Georgia krill–predator
(Task 3 finalist C) where acoustic krill + penguin/seal tracks are
co-registered, or datasets with direct forage-fish fields.
