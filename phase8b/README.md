# Phase-8B — Ecological Spatial Memory Across Ecosystems

Tests whether past space use predicts current distribution beyond environment
across independent systems: elk GPS (individual), NOAA FOSS trawl (population),
BBS routes (population), NEON small mammals (monthly, supplementary).

Data sources are gitignored; regenerate with the Makefile targets above.
NEON download requires NEON API token at `data/neon/token.txt`.
