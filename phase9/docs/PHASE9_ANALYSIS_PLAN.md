# Phase-9 Analysis Plan — BBS hysteresis / delayed redistribution

Frozen from the Phase-9 spec. BBS only; no new ecosystems; Phase-8B HG definition frozen
(HG = OOS(M3 env+history) − OOS(M1 env), OOS = R² on held-out years).

## Question
Does the Phase-8B BBS history signal represent genuine prospective path dependence
(hysteresis, delayed redistribution) rather than delayed environmental response,
static geography, or observation structure?

## Data
- BBS routes (RunType==1), parsed occupancy/count matrix `data/bbs/bbs_parsed.parquet`.
- Environment: Open-Meteo daily archive (primary; NASA POWER fallback) → annual
  aggregates t_ann, jun_t, p_ann, jun_p, djf_p, drought_z. z-anomalies use a fixed
  baseline ≤2005 (no future statistics).
- Species inclusion (data sufficiency only, prespecified): routes ≥1000,
  years ≥30, nonzero-fraction ≥0.30 → 124 species.

## Model hierarchy
M0 intercept; M1 env; M2 history only; M3 env+X_{t-1}; M5 env+lagged env
(E_t-1, E_t-2); M6 = M5+X_{t-1}; M6b = env+lag1+lag2+X_{t-1}.
Route static tendency enters either via train-only route demeaning or explicit
long-run route-mean covariate.

## Primary inference
Forward-chaining: train years ≤ t → predict t+1. Random CV prohibited.
LOYO secondary (and an 8B-style year-demeaned variant used only to reproduce the
8B magnitude). All standardization/demeaning/imputation statistics train-only.

## Required analyses
1. Species-level HG distribution (+95% CI per species, EG, M0–M6b, sim-null p95).
2. 2×2 CV×demean diagnostic (LOYO/FC × demean/none) + decomposition of the 8B→9
   HG drop (future-information vs static persistence).
3. Future-information gain: past-only vs past+future training.
4. Horizons 1/2/3/5 yr; memory-decay curve (nonparametric).
5. Training-size sensitivity (min history 5/10/15 yr) + expanding vs rolling
   10/20-yr windows.
6. Matched-environment hysteresis: within-route matched years with |env z|≤0.5,
   prior-state occupancy contrast; cluster bootstrap over routes; abundance
   (log1p n) effect alongside occupancy.
7. Ascending vs descending trajectory direction test.
8. Climate-anomaly events (route-mean |t_ann z|>0.7, pooled hot/cold):
   redistribution fraction, env-predicted equilibrium distance D_t,
   disequilibrium decay, env-only vs history-aware forecast speed bias.
9. Simulations A–H on real BBS structure (env-only, delayed-env, static-route,
   obs-persistence, true-history, true-hysteresis, missingness, abundance
   autocorrelation). Acceptance: P(false hysteresis|env-only) ≤ 0.10 and
   P(false|static-route) ≤ 0.10.
10. Observer controls (observer identity, first-year observer), abundance vs
    occurrence robustness, regional aggregation, migratory vs resident moderator.
11. LOYO secondary comparison.

## Verdict scale
STRONG GO (all 7 criteria); INTERMEDIATE GO (strong HG + static/env robust,
hysteresis incomplete); WEAK GO (only lag-1 persistence); NO-GO (history reduces
to static geography / lagged env / observation structure).

## Stop rule (§36)
If matched-env history effects disappear or history is fully absorbed by lagged
env/static geography → stop Nature escalation; report honestly.
