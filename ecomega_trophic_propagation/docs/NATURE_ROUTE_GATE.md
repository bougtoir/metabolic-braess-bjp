# NATURE_ROUTE_GATE

## Decision
**COMMON-ENVIRONMENT DOMINATED — CONDITIONAL FAIL for the Nature route.**

## Rationale against the gate criteria
- STRONG MECHANISTIC SUPPORT requires: significant env→prey AND prey→predator,
  positive indirect effect, prey adjustment attenuating E→P, better holdout
  predictive skill, correct temporal ordering, and placebo-fail/signal-pass.
- Observed: E→P significant; E→K ≈ 0; K→P|E ≈ 0; indirect ≈ 0; no attenuation;
  holdout favors env-only; K→P temporal ordering not resolvable. Only the
  E→P branch is supported — that is Type A (common environmental tracking),
  not trophic propagation.
- The prey layer exists in the data (krill tows matched to seabird sightings),
  so absence of a K→P signal is not purely a data-coverage artifact — though
  sampling cadence and sub-mesoscale prey patchiness remain plausible hiding
  mechanisms (see validity threats in ECOMEGA_MECHANISM_REPORT).

## What would change the verdict
- Higher-cadence prey sampling (e.g. continuous acoustic transects within
  cruises), or a higher-resolution, locally-resolved upwelling product.
- TOPP as external validation (preregistered as candidate-A in Task 3)
  remains the next testbed — NOT run here per Task 4 instructions.

## Standing
Not a "failed science" outcome: the Type-A/Type-B discrimination framework
worked and returned a clear verdict on this system. Nature-route ambition
should pivot to datasets with higher prey-sampling cadence.
