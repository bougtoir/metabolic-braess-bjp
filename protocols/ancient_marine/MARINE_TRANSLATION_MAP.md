# Terrestrial → ancient-marine translation map

| Terrestrial (dinosaur) element | Marine analogue | Rationale |
|---|---|---|
| collection (quarry/locality) | assemblage within palaeogeographic spatial unit (basin / shelf region / grid cell / province) | marine collections are stratum samples inside a connected water body; the assemblage-in-province is the comparable "community sample" |
| terrestrial species-pool restriction | assemblage / basin pool restriction | same sampling-pool experiment, marine pool = basin+facies stratum |
| terrestrial geographic distance | palaeogeographic great-circle distance OR marine-connectivity (least-cost ocean path) distance | connectivity is the dispersion-relevant axis; great-circle retained as sensitivity |
| locality turnover (Simpson Δβ) | assemblage turnover among palaeogeographic units | identical estimand on marine spatial units |
| temporal averaging over formation | stratigraphic condensation / time-bin aggregation | formation ↔ stage/condensed bed |
| sampling intensity (occurrences per collection) | formation / locality / collection intensity | same correction battery |
| dominant-quarry exclusion (>p95) | monodominant / obrution-Lagerstätte exclusion | same tail-trimming logic |
| 1° spatial thinning | spatial thinning at chosen palaeo-grid resolution | identical |
| genus incidence | genus (or subgenus) incidence | identical, resolution check mandatory |
| Sauropoda+Ornithischia vs Theropoda | lower guild (suspension feeders / grazers / primary consumers) vs predatory guild (nektonic + benthic predators) | choose by data; document per dataset |

## What does NOT translate

- Fine seasonal migration: unobservable in condensed marine record → M4 uses
  bin-level lead/lag instead.
- "Migratory prey subsidy" mechanism: tested only as the spatial-turnover
  pattern; mechanism language stays out of the exported metric.
