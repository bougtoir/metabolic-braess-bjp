# PALMYRA_VS_CAPELIN — why the capelin system is (and isn't) a better test bed

| dimension | Palmyra | Capelin–seabird |
|---|---|---|
| independent events | 22 chl events (7-day sep) | 10 yearly spawning onsets |
| biological replicates/event | 1–11 individuals per guild | 1 aggregated count per survey-year |
| temporal overlap | ~10 events with ≥2 guilds (Jun–Nov 2022) | all 10 years same area/season |
| exposure quality | regional chl-a, ~67% cloud-masked | direct hydroacoustic fish biomass, same transect |
| predator-response quality | telemetry fixes, heterogeneous sampling | standardized strip counts, sparse (3–10 surveys/yr) |
| main effect | slope −0.018 (≈0); FE OLS p=0.33 | evt coef +0.92, p=0.03 |
| placebo | 50% of placebos ≥ observed | 45% of placebos ≥ observed median (median-level), but pooled model significant |
| LOEO | stable (trivially, null effect) | stable, all positive, 0 sign reversals |
| standardized magnitude | ~0 | +2.3× birds/bin (e^0.92) |

## Reading

The capelin system recovers a significant, stable event-associated predator
response where Palmyra shows none — supporting the framework's sensitivity
when (a) exposure is measured directly on the prey field and (b) events are
biologically real pulses rather than statistical anomalies. Its weakness is
event count (10) and per-window survey sparsity, not detectability. Palmyra's
failure is plausibly real data limitation (weak regional perturbations,
indirect exposure), not purely analytical failure — the same machinery finds
a signal here.
