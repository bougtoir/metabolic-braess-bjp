# Periodic Constitutional Dictatorship -- Constitutional Political Economy submission

This repository contains the manuscript, simulation code, and figures for the paper
"Democracy as Control over Delegated Authority: Constitutional Design under Periodic Delegation."

Target journal: *Constitutional Political Economy* (Springer).

## Reproducing the manuscript and figures

Requires Python 3 and `pip install python-docx python-pptx matplotlib numpy pillow latex2mathml docx-equation`.

```bash
python3 simulation_en.py        # generates simulation_p1_en.png, simulation_p2_en.png, simulation_summary_en.txt
python3 make_docx_en.py          # generates paper_draft_en.docx (working version with inline figures)
python3 make_docx_en_submission.py  # generates paper_draft_en_submission.docx (legends at end, no inline figures)
python3 make_figures_pptx_en.py  # generates figures_en.pptx
```

The figures for journal submission are also saved under `figures_en_submission/` as `.png` and `.tiff` files.

## Files

- `paper_draft_en.txt` -- plain-text CPE manuscript (author-date citations, alphabetical references)
- `paper_draft_en.docx` -- formatted working manuscript with inline figures
- `paper_draft_en_submission.txt` -- plain-text submission version (no inline figures; figure legends at end)
- `paper_draft_en_submission.docx` -- formatted submission manuscript
- `simulation_en.py` -- English-labeled agent-based simulation and L(T) illustration
- `simulation_summary_en.txt` -- reproducible summary statistics
- `supplementary_materials_en.md` -- full simulation protocol, parameter table, and robustness notes
- `docx_math.py` -- shared helpers for Word OMML equations and italic formatting
- `make_docx_en.py` / `make_docx_en_submission.py` -- build the working and submission DOCX files
- `make_figures_pptx_en.py` -- build editable PowerPoint figures
- `gen_submission_txt.py` -- derive `paper_draft_en_submission.txt` from `paper_draft_en.txt` (optional; already generated)
- `figures_en.pptx` -- editable PowerPoint with one figure per slide
- `figures_en_submission/` -- separate high-resolution figure files
- `cpe_submission_package.md` -- title, abstract, cover letter, fit statement, and CPE checklist
- `critical_review_cpe.md` -- pre-submission reviewer-perspective critique

## Notes

- All numerical results in the manuscript are generated by `simulation_en.py` with a fixed random seed (`seed=42`).
- The value of T* is an illustrative example produced by the parameters in `simulation_en.py`; it is not an empirical estimate.
- Simulation parameters and algorithms are available in `simulation_en.py`; a concise summary is in `simulation_summary_en.txt`.
- Full methodological details and robustness notes are in `supplementary_materials_en.md`.
